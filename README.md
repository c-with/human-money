# 企业用工成本工具箱

一款面向企业的用工成本估算工具，覆盖招聘到离职的全周期成本测算。

## 功能

- 用人成本计算 — 输入月薪，自动算出企业法定总成本和员工到手
- 个税累计预扣法 — 支持月度估算和年度累计两种模式
- 医保分档 — 统账结合（一档）和单建统筹（二档）自动切换
- 年终奖单独计税 — 除以 12 换算档位
- 企业年金与工会费 — 可选开启
- 反向测算 — 员工想拿到手 X，反推公司总成本
- 绩效与提成 — 评分系数、阶梯提成、项目利润池
- 离职补偿测算 — 7 种解除场景，自动算补偿金
- 高薪封顶与保底 — 3 倍社平工资封顶 + 最低工资保底
- 二倍工资差额 — 未签书面合同，最长 11 个月
- 法律条文引用 — 每项计算附对应法条
- 一键复制结果 — 计算完成直接复制到剪贴板

## 技术栈

`HTML` `Node.js` `Express` `SQLite` `Docker`
